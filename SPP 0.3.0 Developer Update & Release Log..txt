# SPP 0.3.0 Developer Update & Release Log

Welcome to the developer log for **SPP (Simple Plus Plus) 0.3.0**! This major update shifts SPP from a simple command-line prototype into a robust, statically compiled language capable of building real applications, utilities, games, and automation scripts.

Below is a complete breakdown of what was added, how it impacts your workflow, and code examples demonstrating how to use every feature.

---

## 🛠️ Summary of Key Additions & System Improvements

### 1. Advanced Architecture & AST Expression Parser

* **What was added:** Replaced legacy line-by-line regex matching with a dedicated, typed expression parser (`ExprParser`) and full Abstract Syntax Tree (AST) tokenization.


* **Impact:** Prevents expression parsing bugs, handles complex nested parentheses cleanly, enforces strict operator precedence, and provides intelligent "Did you mean...?" diagnostics when variable or function names are mistyped.


* **C++ Backend:** Generates clean, dependency-free standard C++17 code that compiles directly into a standalone `.exe` or native binary.



---

## 🚀 Feature Breakdown, Impact & Usage Examples

### 1. String Interpolation (`f"..."` & `{expr}`)

* **What it adds:** Evaluate variables and math expressions inline directly inside string literals without manual concatenation.


* **Impact:** Reduces verbose code when building dynamic UI text, terminal prompts, or log output.


* **Example:**

```spp
v"player_name" = "Alex"
v"hp" = 85
v"max_hp" = 100

p"Status: {player_name} has {hp}/{max_hp} HP ({hp / max_hp * 100}% remaining)"p

```

---

### 2. User-Defined Functions (`fn`)

* **What it adds:** Support for modular, reusable functions with typed parameters and explicit return signatures.


* **Impact:** Allows organizing large SPP codebases into clean, modular blocks instead of long linear scripts.


* **Example:**

```spp
fn"calculate_damage"(number base_dmg, number armor) -> number {
    number"final_dmg" = max(1, base_dmg - armor)
    return final_dmg
}

v"dealt" = calculate_damage(50, 15)
p"Damage dealt: {dealt}"p

```

---

### 3. Lists & Collection Operations (`list.number`, `list.text`)

* **What it adds:** First-class typed list data structures with standard container methods (`.add()`, `.remove()`, `.insert()`, `.sort()`, `.reverse()`, `.length`).


* **Impact:** Enables state management for inventories, scoreboards, batch processing, and dynamic collections.


* **Example:**

```spp
list.text"inventory" = ["Sword", "Shield", "Potion"]

inventory.add("Magic Ring")
inventory.sort()

for"item" in inventory {
    p"Item: {item}"p
}

p"Total inventory size: {inventory.length}"p

```

---

### 4. Expanded Control Flow (`for`, `forever`, `else if`)

* **What it adds:** `for ... from ... to` numerical range loops, `for ... in` array iteration, unconstrained `forever` loops, and multi-branch `else if` conditions.


* **Impact:** Simplifies array iteration, range loops, and complex branch conditions.


* **Example:**

```spp
for"i" from 1 to 10 step 2 {
    p"Step: {i}"p
}

number"choice" = 2
if choice == 1 {
    p"Start Game"p
} else if choice == 2 {
    p"Load Save"p
} else {
    p"Quit"p
}

```

---

### 5. Safe Error Handling (`try / catch`)

* **What it adds:** Structured runtime exception handling to intercept file, math, or type errors cleanly.


* **Impact:** Prevents native crashes when reading missing files or encountering division-by-zero, allowing graceful recovery.


* **Example:**

```spp
try {
    v"config" = file.read("settings.json")
    p"Loaded config successfully."p
} catch {
    p"Failed to load settings! Reason: {error}"p
    file.write("settings.json", "{}")
}

```

### 6. Native Standard Library Modules

SPP 0.3.0 ships with built-in standard modules for core system tasks:

#### A. Math Module (`sqrt`, `clamp`, `random`, `min`, `max`, `round`, trig)

```spp
number"roll" = random(1, 6)
number"clamped_val" = clamp(roll * 20, 0, 100)
p"Rolled: {roll}, Clamped: {clamped_val}"p

```

#### B. Text Operations (`text.upper`, `text.replace`, `text.trim`, `text.sub`)

```spp
text"raw" = "  hello world  "
text"clean" = text.upper(text.trim(raw))
p"Cleaned text: {clean}"p   # Output: HELLO WORLD

```

#### C. File & Directory I/O (`file.*`, `folder.*`)

```spp
if not file.exists("save.dat") {
    file.write("save.dat", "level=1")
}
v"save_data" = file.read("save.dat")

```

#### D. Time & System Info (`time.*`, `system.*`)

```spp
p"OS: {system.os()}"p
p"User: {system.username()}"p
p"Current Date: {time.date()}"p

```

### 7. File Imports (`import`)

* **What it adds:** Header/module importing to split code across multiple `.spp` files.


* **Impact:** Enables standard libraries, helper utilities, and multi-file project architectures.


* **Example:**

```spp
# main.spp
import "helpers.spp"

p"Running main application..."p

```

---

### 8. Timed Output Shorthand (`ST`)

* **What it adds:** Compact terminal output repeating syntax with configurable timing intervals (`ST<seconds>` or `ST<seconds>x<count>`).


* **Impact:** Useful for building status monitors, loading spinners, or periodic pulse checks without writing explicit loop code.


* **Example:**

```spp
p"Pinging server..."p ST1x5   # Prints 5 times with a 1-second delay between each

```

---

### 9. Native Win32 GUI Shorthand & Flexible Control Hooks

* **What it adds:** Compact declarations for GUI buttons (`GB`) and text labels (`GT`) with horizontal alignment and a unique `ID` hook.

* **Syntax:** `GB=M:ID42`, `GB=M:ID_Submit`, or `GT=R:ID_Status`. Alignment supports `M` (middle), `L` (left), and `R` (right).

* **ID assignment:** Numeric hooks keep the established mapping (`ID42` becomes Win32 control ID `142`). Named hooks receive the next unused Win32 control ID, starting at `101`. Duplicate hooks are rejected.

* **C++ backend:** The shorthand generates a native Win32 window and controls. `WM_COMMAND` dispatches button clicks (and notified text-label clicks) by control ID to a per-control handler. This shorthand currently targets Win32, not WinForms.

* **Example:**

```spp
GB=M:ID_Submit
GT=R:ID_Status
GB=L:ID42
```

Generated event routing has this shape:

```cpp
case kControlID_0: // ID_SUBMIT
    if (HIWORD(wParam) == BN_CLICKED) {
        OnClick_0(reinterpret_cast<HWND>(lParam));
        return 0;
    }
    break;
```

Replace the generated `OnClick_0` body with the desired action for that hook. Numeric and named hooks share the same event-dispatch mechanism.

## 💻 Complete Example: Interactive Bank System

Below is a complete, runnable program combining SPP 0.3.0 features (functions, lists, file I/O, error handling, and string interpolation):

```spp
# Bank Management System in SPP 0.3.0

import "math"

const"BANK_NAME" = "SPP Central Bank"
number"balance" = 500.0
list.text"transactions" = []

fn"deposit"(number amount) -> bool {
    if amount <= 0 {
        return false
    }
    v"balance" = balance + amount
    transactions.add("Deposited ${amount}")
    return true
}

fn"withdraw"(number amount) -> bool {
    if amount <= 0 or amount > balance {
        return false
    }
    v"balance" = balance - amount
    transactions.add("Withdrew ${amount}")
    return true
}

p"=== Welcome to {BANK_NAME} ==="p

try {
    deposit(150.0)
    withdraw(50.0)

    p"Current Balance: ${balance}"p
    p"Recent Activity:"p
    
    for"log" in transactions {
        p" - {log}"p
    }

    file.write("bank_summary.txt", "Final Balance: ${balance}")
    p"Summary exported to bank_summary.txt"p
} catch {
    p"An unexpected system error occurred: {error}"p
}

```

## 📦 Building & Testing

To test, check, or build your SPP 0.3.0 projects using the command line:

```cmd
# Check code syntax without compiling
py spp.py check main.spp

# Build standalone executable (.exe)
py spp.py build main.spp -o BankApp.exe

# Build and execute immediately
py spp.py run main.spp

```
